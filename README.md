### Пример 1. Анкета студента с вычислением возраста и статуса

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Добро пожаловать в анкету!");

        Console.Write("Введите ваше имя: ");
        string name = Console.ReadLine();

        Console.Write("Введите вашу фамилию: ");
        string surname = Console.ReadLine();

        Console.Write("Введите вашу группу: ");
        string group = Console.ReadLine();

        Console.Write("Введите ваш год рождения: ");
        int birthYear = int.Parse(Console.ReadLine());

        Console.Write("Введите ваш средний балл (например, 4.5): ");
        double gpa = double.Parse(Console.ReadLine().Replace('.', ','));

        int currentYear = 2026;
        int age = currentYear - birthYear;
        bool isExcellent = gpa >= 4.5;

        string status = isExcellent ? "Отличник" : "Хорошист";

        Console.WriteLine("Ваша анкета");
        Console.WriteLine($"Имя: {name} {surname}");
        Console.WriteLine($"Группа: {group}");
        Console.WriteLine($"Возраст: {age} лет");
        Console.WriteLine($"Средний балл: {gpa}");
        Console.WriteLine($"Статус: {status}");
        Console.WriteLine($"Лет до 30: {30 - age}");
    }
}

Главные выводы
C# - строго типизированный язык. Тип переменной указывается явно (int x = 5;), и попытка присвоить значение несовместимого типа без явного приведения вызывает ошибку компиляции. Это делает код надёжнее и предсказуемее, а большинство ошибок обнаруживается ещё до запуска.

Платформа .NET работает через промежуточный IL-код. Компилятор C# превращает исходный код не в машинный, а в IL (Intermediate Language), который затем исполняется CLR с JIT-компиляцией. Благодаря этому один и тот же .dll может работать на Windows, Linux и macOS.

Целочисленное деление отличается от дробного. Операция / для двух int возвращает целое число с отбрасыванием дробной части (10 / 3 == 3). Чтобы получить 3.333..., нужно привести хотя бы один операнд к double: (double)10 / 3 или 10.0 / 3.

var - это не динамическая типизация. Компилятор сам выводит тип по значению, но фиксирует его навсегда. В отличие от Python, где тип переменной может меняться во время выполнения, в C# после var x = 5; переменная навсегда останется int.

Ввод пользователя всегда возвращает string. Для работы с числами нужна явная конвертация (int.Parse, double.Parse, TryParse). При этом нужно учитывать локаль системы: в русской локали десятичный разделитель - запятая, а не точка.

 Ответы на вопросы:
**1. Чем Console.Write() отличается от Console.WriteLine()?**

Console.Write() выводит текст без перехода на новую строку — следующий вывод продолжится там же. Console.WriteLine() после вывода добавляет перевод строки (\n), поэтому следующий вывод начинается с новой строки.

**2. Что произойдёт, если попытаться присвоить переменной типа int значение 3.14?**

Будет ошибка компиляции (CS0266): double нельзя неявно преобразовать в int. Нужно явное приведение: int x = (int)3.14; — тогда дробная часть отбрасывается, x = 3.

**3. Почему 10 / 3 в C# даёт 3, а не 3.333...? Как получить дробный результат?**

Оба числа — int, поэтому выполняется целочисленное деление: дробная часть отбрасывается. Чтобы получить 3.333..., нужно привести хотя бы один операнд к double: (double)10 / 3 или 10.0 / 3.

**4. Что означает var в C#? Чем он отличается от динамической типизации в Python?**

var — это неявное объявление типа: компилятор сам выводит тип по значению, но фиксирует его навсегда. В Python тип динамический и может меняться во время выполнения. В C# после var x = 5; переменная навсегда останется int, и присвоить ей строку нельзя.
